# D-024 — TPC-H Dataset and Scale

Status: Accepted
Date: 2026-10-31
Phase: specs/02-transactional-ingestion

## Context

The source Postgres needs a realistic transactional dataset with orders, line items and customers.

## Alternatives

| Alternative | Best Practices | Simplicity | Cost | Consistency with the Whole |
|---|---|---|---|---|
| A. TPC-H generated by DuckDB `dbgen`, scale factor as a parameter (SF0.1 or SF1); resources sized for SF1 | Standard benchmark schema with an order lifecycle | One SQL call | None (SF1 is about 1.4 GB per copy in Postgres) | Same on every cloud |
| B. A custom synthetic schema | Not a known reference | Schema and generator to write | None | Meets all requirements |

## Decision

- **Recommended:** A, because TPC-H is a known reference and DuckDB generates it with one call.
- **Chosen:** A
- **Reason:** follows the recommendation.
