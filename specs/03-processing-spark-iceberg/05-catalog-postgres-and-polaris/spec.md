# 03.05 — Catalog Postgres and Polaris: Specification

Status: Implemented
Phase: [03 — Processing: Spark and Iceberg](../plan.md)

## Design

| Component | Configuration | ADR |
|---|---|---|
| Namespace | `polaris`, holding both Polaris and its Postgres | [D-046](../../../docs/decisions/046-catalog-metadata-database.md) |
| Catalog Postgres | StatefulSet `polaris-postgres`, image `postgres:18.6`, the same pattern as the source Postgres | [D-046](../../../docs/decisions/046-catalog-metadata-database.md) |
| Catalog Postgres volume | 1 GiB EBS, the low end of the D-046 range, deleted with the StatefulSet | [D-046](../../../docs/decisions/046-catalog-metadata-database.md) |
| Catalog Postgres Application | Argo CD Application `polaris-postgres` → `platform/aws/polaris-postgres/` | [D-032](../../../docs/decisions/032-one-application-per-component.md) |
| Database user | `polaris`, owner of schema `polaris_schema` only; both created by an init script on first start | [D-061](../../../docs/decisions/061-polaris-database-user.md) |
| Database passwords | Superuser and `polaris` passwords in `.env`, sent to the cluster as a Secret with `kubectl` | [D-031](../../../docs/decisions/031-source-postgres-password-from-env.md) |
| Polaris | Argo CD Application `polaris`: chart `polaris` 1.8.0 from `https://downloads.apache.org/polaris/helm-chart` | [D-044](../../../docs/decisions/044-iceberg-rest-catalog-server.md) |
| Polaris persistence | `relational-jdbc`, connection from Secret `polaris-persistence` (user, password, JDBC URL) | [D-046](../../../docs/decisions/046-catalog-metadata-database.md) |
| Polaris identity | ServiceAccount `polaris`, annotated with role `eks-for-data-polaris` | [D-049](../../../docs/decisions/049-silver-storage-credentials.md) |
| Polaris authentication | Chart default: internal, keys generated by the pod (one replica) | — |
| Resources | No requests for Polaris or its Postgres; measured first | [D-018](../../../docs/decisions/018-workload-resource-requests.md) |
| Realm bootstrap | Realm `POLARIS`; root secret in `.env`; the user runs `apache/polaris-admin-tool:1.8.0` once with `kubectl run` | [D-059](../../../docs/decisions/059-polaris-realm-bootstrap.md) |
| Catalog creation | The user runs `polaris catalogs create` (CLI 1.8.0) in the lab, with the catalog name chosen then | [D-060](../../../docs/decisions/060-polaris-catalog-creation.md) |
| Catalog storage | Base location in `s3://eks-for-data-silver-283429977024/`; role `eks-for-data-silver-data` | [D-049](../../../docs/decisions/049-silver-storage-credentials.md) |
| Access from the computer | `kubectl port-forward` to Polaris port 8181 | [D-012](../../../docs/decisions/012-cluster-and-ui-access.md) |

## Teardown

- Polaris, its Postgres and the EBS volume go with the environment at
  [Turn Off](../../../HOW_TO_RUN.md#51-turn-off).
- Catalogs created in labs are removed with the catalog database; their files in silver go with the
  bucket (`force_destroy`).
