# 03.04 — Spark Operator and Bronze Read Job: Specification

Status: Approved
Phase: [03 — Processing: Spark and Iceberg](../plan.md)

## Design

| Component | Configuration | ADR |
|---|---|---|
| Namespace `spark` | `platform/aws/spark-namespace.yaml`, synced by the root Application `platform`; Argo CD applies namespaces before Applications | [D-056](../../../docs/decisions/056-spark-namespace-layout.md) |
| Spark Operator | Argo CD Application `spark-operator`: chart `spark-operator` 2.5.2 from `https://kubeflow.github.io/spark-operator` | [D-045](../../../docs/decisions/045-spark-on-kubernetes.md) |
| Operator namespace | `spark-operator`, created by Argo CD | [D-056](../../../docs/decisions/056-spark-namespace-layout.md) |
| Job namespace | Chart value `spark.jobNamespaces: [spark]` | [D-056](../../../docs/decisions/056-spark-namespace-layout.md) |
| Job ServiceAccount | `spark`, created by the chart, annotated with role `eks-for-data-spark` | [D-008](../../../docs/decisions/008-pod-aws-identity.md) |
| Operator resources | Chart defaults, no requests | [D-018](../../../docs/decisions/018-workload-resource-requests.md) |
| Job script | `pipelines/spark/read_bronze_orders.py`: prints the row count and the distinct `orderkey` count of `s3a://eks-for-data-bronze-283429977024/oltp_cursor/oltp/orders/` | [D-042](../../../docs/decisions/042-lab-bronze-layout.md) |
| Script delivery | ConfigMap `spark-jobs` with a fixed name, generated by Kustomize in `pipelines/spark/` | [D-048](../../../docs/decisions/048-spark-job-code-delivery.md) |
| Script Application | Argo CD Application `spark-jobs` → `pipelines/spark/`, namespace `spark` | [D-032](../../../docs/decisions/032-one-application-per-component.md) |
| Job definition | `SparkApplication` `read-bronze-orders` in `pipelines/spark/`, started with `kubectl apply` | [D-057](../../../docs/decisions/057-spark-job-run-start.md) |
| Job image | `ghcr.io/andrerosalopes/spark:4.0.5-iceberg1.12.0`, pulled on every run (`imagePullPolicy: Always`), because a rebuilt image keeps the same tag | [D-054](../../../docs/decisions/054-spark-image-tag.md) |
| Driver and executor identity | ServiceAccount `spark` | [D-008](../../../docs/decisions/008-pod-aws-identity.md) |
| S3A credentials | `fs.s3a.aws.credentials.provider`: `WebIdentityTokenFileCredentialsProvider` | [D-058](../../../docs/decisions/058-spark-s3a-credentials.md) |
| S3A region | `us-east-1` | [D-001](../../../docs/decisions/001-aws-region.md) |
| Job resources | Spark defaults: 1 core and 1g per pod, 2 executors | [D-018](../../../docs/decisions/018-workload-resource-requests.md) |

## Teardown

- The operator, the namespaces and the ConfigMap go with the environment at
  [Turn Off](../../../HOW_TO_RUN.md#51-turn-off).
- A finished job holds no CPU or memory. Delete it with
  `kubectl -n spark delete sparkapplication read-bronze-orders` before a re-run.
