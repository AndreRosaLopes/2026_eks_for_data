# 01.01 — Network: Specification

Status: Approved
Phase: [01 — Ingestion: Airbyte Writing Parquet to S3](../plan.md)

## Design

A VPC in the `infra/aws/cluster` root ([D-003](../../../docs/decisions/003-terraform-root-layout.md)),
built with the `terraform-aws-modules/vpc/aws` module 6.7.3
([D-004](../../../docs/decisions/004-terraform-modules.md)). The state is local
([D-002](../../../docs/decisions/002-terraform-state-backend.md)) and the region is fixed to
`us-east-1` in the provider ([D-001](../../../docs/decisions/001-aws-region.md)).
Credentials come from `AWS_PROFILE=eks-ws`, loaded from `.env`, and never enter the code.

| Item | Value | Why |
|---|---|---|
| VPC CIDR | `10.0.0.0/16` | Standard private range |
| AZs | The first 2 available, excluding `use1-az3`. In this account: `us-east-1a` (use1-az1) and `us-east-1b` (use1-az2) | EKS does not accept subnets in `use1-az3`; AZ names differ per account, so the exclusion uses the ID |
| Private subnets (nodes and pods) | `10.0.0.0/19`, `10.0.32.0/19` | About 8,000 IPs per AZ; on EKS, pods use VPC IPs |
| Public subnets (NATs) | `10.0.64.0/24`, `10.0.65.0/24` | Only host the NAT Gateways |
| NAT | `enable_nat_gateway = true`, `one_nat_gateway_per_az = true`: 2 NATs, each with an EIP; each private subnet goes out through the NAT of its AZ ([D-005](../../../docs/decisions/005-network-topology.md)) | |
| S3 endpoint | Submodule `vpc/aws//modules/vpc-endpoints`, Gateway type, attached to the private route tables | Free; S3 traffic bypasses the NAT (D-005) |
| DNS | `enable_dns_hostnames` and `enable_dns_support` = `true` (module default) | Required by EKS |
| Tags | Provider `default_tags`: `Project = 2026_eks_for_data`, `ManagedBy = terraform`. Name prefix: `eks-for-data` | |
| Versions | Terraform `>= 1.10`, `hashicorp/aws ~> 6.28` (the module requires `>= 6.28`), module pinned to `6.7.3`. `.terraform.lock.hcl` is versioned | |

**Cost while running:** 2 NATs × US$ 0.045/h + 2 public IPv4 × US$ 0.005/h = **US$ 0.10/h**,
plus US$ 0.045 per GB processed by the NATs (us-east-1 prices from the AWS Pricing API).

**Outside this step:** outbound internet access from a private subnet can only be tested once
something runs there; it is checked in 01.02, when the nodes pull images.

## Teardown

```bash
set -a; source .env; set +a
terraform -chdir=infra/aws/cluster destroy
```

It removes the VPC, NATs, EIPs and endpoint. From 01.02 on, the same command also destroys what
later steps add to the `cluster` root.
